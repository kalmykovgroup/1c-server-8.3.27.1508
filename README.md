🧾 Управление кластером и сервисами через rac
Для администрирования кластера 1С:Предприятия используется утилита rac, которая входит в стандартный пакет платформы и находится в каталоге установки (например, /opt/1cv8/x86_64/<version>/).

Пример вызова справки
bash
Копировать
Редактировать
./rac --help
При запуске этой команды будет показан список доступных режимов управления:

agent — управление агентом сервера кластера.

cluster — управление кластером серверов.

manager — управление менеджером кластера.

server — управление рабочими серверами.

process — управление рабочими процессами.

infobase — управление информационными базами.

connection — управление соединениями.

session — управление сеансами пользователей.

lock — управление блокировками.

rule, profile, counter, limit, service-setting, binary-data-storage и другие.
